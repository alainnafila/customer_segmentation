# Customer Segmentation Analysis
Customer Segmentation using K-Means

## Overview
This project applies K-Means Clustering to segment mall customers based on demographic and spending behavior.

## Dataset
The dataset contains:
- Customer ID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1-100)

## Methods
- Data preprocessing
- Feature scaling
- Elbow Method
- K-Means Clustering
- Data visualization

## Tools
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Results
The Elbow Method showed that the optimal number of clusters is K=5.
